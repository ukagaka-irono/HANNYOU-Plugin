# HANNYOU-Plugin

Paper サーバー向けのプラグインです。現在は、プレイヤーに「役職」を付与して装備・インベントリ・永続ポーション効果を配る **Knights Editor** 機能を搭載しています。

Knights Editor は KnightsEditor を移植し、GUI の見た目はそのままに内部を作り直したものです。

---

## 特徴

- **GUI で役職を作成・編集** — 装備5箇所、インベントリ27枠、ホットバー9枠、ポーション効果32種（レベル I〜III）
- **手持ちから取り込み** — 今の自分の装備とインベントリを、そのまま役職の中身にできる
- **試着** — 役職を自分に一時的に適用して確認し、終わったら持ち物と効果を元に戻せる
- **GUI でプレイヤーに付与** — オンラインのプレイヤーを選んで一括付与
- **永続効果** — 時間無制限で付与し、牛乳や不死のトーテムでは消えない。役職を保存すると保持者の効果もすぐ更新される
- **エクスポート／インポート** — 役職を YAML で共有できる。KnightsEditor で出力したファイルも読み込める
- **監査ログ** — 役職の操作を日別ファイルと管理者のチャットに記録
- **軽量** — データベースへの書き込みやファイル操作は別スレッドで行い、サーバーの TPS を下げない

## 動作環境

| 項目 | バージョン |
|---|---|
| サーバー | Paper 26.1.2 |
| Java | 25 |

初回起動時に SQLite ドライバ（`org.xerial:sqlite-jdbc`）を自動でダウンロードします。サーバーがインターネットに接続できる必要があります。

## 導入方法

1. jar を[ビルド](#ビルド方法)します
2. `build/libs/HANNYOU-Plugin-<version>-all.jar` をサーバーの `plugins/` フォルダに置きます
3. サーバーを起動します

## 使い方

まずは `/hannyou knights menu` でメインメニューを開いてください。

### メインメニュー

| ボタン | 内容 |
|---|---|
| 兵士の作成 | 新しい役職を作るエディタを開く |
| 兵士一覧 | 登録済みの役職の一覧を開く |
| 役職をインポート | `exports/` フォルダのファイルから役職を読み込む |

### 役職エディタ

4ページ構成です。下段の左右の矢印でページを切り替えます。

| ページ | 内容 |
|---|---|
| 1. 装備 | 頭・胴・脚・足・オフハンドにアイテムを置く |
| 2. インベントリ | 上3段がインベントリ、4段目がホットバー |
| 3. 効果 | ポーションをクリックするたびに「なし → I → II → III → なし」と切り替わる |
| 4. システム | アイコン（中央にアイテムを置く）、システムID、表示名 |

表示名には `&c` のようなカラーコードが使えます。

下段のボタン:

| スロット | ボタン | 作成時 | 編集時 |
|---|---|:-:|:-:|
| 47 | 手持ちから取り込み | ✅ | ✅ |
| 48 | この役職をエクスポート | — | ✅ |
| 49 | 閉じる（保存しない） | ✅ | ✅ |
| 50 | 保存 | ✅ | ✅ |
| 51 | 試着する | ✅ | ✅ |
| 52 | プレイヤーに付与 | — | ✅ |

- 編集は作業用のコピーに対して行い、「保存」を押したときだけ反映されます。
- 「プレイヤーに付与」は保存済みの内容を付与します。未保存の変更があるときは、先に保存するよう案内が出ます。

### 役職一覧

| 操作 | 内容 |
|---|---|
| 左クリック | 編集 |
| 右クリック | コピー |
| Shift + 左クリック | 試着 |
| Shift + 右クリック | プレイヤーに付与 |
| Q キー | 削除（確認画面が開きます） |
| コンパス | ID・表示名で検索（右クリックで検索を解除） |

### 試着

役職を自分に一時的に適用して、見た目や効果を確認できます。

- 試着前の持ち物と効果はプレイヤーデータに退避されます。役職のタグは付きません。
- チャットの **【試着を終了】** か `/hannyou knights untry` で元に戻ります。エディタから試着した場合は、エディタに戻ります。
- ログアウト、死亡後のリスポーン、プラグインの停止でも自動で元に戻ります。サーバーが落ちた場合は、次の参加時に戻ります。
- 試着中に死んでも、アイテムと経験値は落ちません。

> [!WARNING]
> 試着中にアイテムを捨てたりチェストに入れたりすると、そのアイテムは手元に残ったまま試着前の持ち物も戻るため、アイテムが増えます。試着は信頼できる管理者だけが使う前提です。

### 役職を付与したとき

- プレイヤーには役職IDのスコアボードタグが付き、装備・インベントリ・効果が配られます。**インベントリは役職の中身に置き換わります。**
- 別の役職に変えると、前の役職の効果は外れます。
- 参加時には役職の中身を配り直します（`reapply-items-on-join` で変更できます）。
- 役職を削除すると、オンラインの保持者からタグと効果が外れます（アイテムはそのまま）。オフラインの保持者は、次の参加時に外れます。

### スペクモード

`/hannyou knights spec [対象]` で、観戦や進行役に向いた特別なクリエイティブモードにします。`/hannyou knights unspec [対象]` で解除すると、元のゲームモードに戻ります。対象を省略すると自分自身が対象になります。

- **見えない** — 体・装備・手に持った物・名前が、ほかのプレイヤーから見えなくなります（管理者も含む）。スペク中の人同士は半透明で見えます。タブリストには表示されたままです。
- **ぶつからない** — プレイヤーや Mob を押したり押されたりせず、矢などの飛び道具もすり抜けます。感圧板・トリップワイヤー・スカルクセンサーも反応しません。
- **操作できない** — ブロックの破壊・設置・右クリック、アイテムを捨てる・拾う・使う、攻撃、エンティティの操作、乗り物に乗ることができません。ダメージも受けません。
- クリエイティブなので、飛行とクリエイティブインベントリは使えます。
- スペク中はゲームモードを変更できません。状態はログアウトや再起動をまたいで続きます。

> [!NOTE]
> 見えなくするために、スペク中の人は `hannyou_spec` というチームに入ります。元々チームに入っていた場合は、解除時にそのチームへ戻ります。

## コマンド

すべて `/hannyou knights` から始まります。`/hannyou` だけを打つとヘルプが表示されます。ヘルプやボタンの多くはチャット上でクリックできます。

| コマンド | 説明 |
|---|---|
| `/hannyou knights menu` | メインメニューを開く |
| `/hannyou knights list` | 役職の一覧 |
| `/hannyou knights info <役職ID>` | 役職の中身。【編集】【試着】【削除】ボタン付き |
| `/hannyou knights role <対象> <役職ID>` | 役職を付与する |
| `/hannyou knights try <役職ID>` | 役職を試着する |
| `/hannyou knights untry` | 試着を終了する |
| `/hannyou knights edit <役職ID>` | エディタを開く |
| `/hannyou knights spec [対象]` | [スペクモード](#スペクモード)にする（省略時は自分） |
| `/hannyou knights unspec [対象]` | スペクモードを解除する（省略時は自分） |
| `/hannyou knights roleremove <役職ID>` | 削除の確認画面を開き、「削除する」か「やめる」を選ぶ |
| `/hannyou knights export [役職ID\|all]` | YAML に出力する（省略時は全件） |
| `/hannyou knights import [ファイル名] [overwrite]` | YAML から読み込む（省略時はファイル一覧を表示） |
| `/hannyou knights reload` | `config.yml` を読み直す |

`<対象>` にはプレイヤー名のほか、`@a` `@s` `@p` `@r` などのセレクターが使えます。

```
/hannyou knights role @a warrior     # 全員に付与
/hannyou knights role Steve knight   # 特定のプレイヤーに付与
```

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| `hannyou.knights.admin` | すべてのコマンドと GUI | OP |
| `hannyou.knights.menu` | `/hannyou knights menu` でメニューを開く | OP |

権限を持っていないプレイヤーには、コマンド自体が表示されません。

## 設定（config.yml）

```yaml
# 役職の作成・編集・削除などを監査ログ (logs/) と管理者チャットに記録する
log-role-changes: true

settings:
  # 登録できる役職の最大数 (-1 = 無制限)
  max-roles: -1
  # 参加時に役職の装備・インベントリを再配布する (false の場合はポーション効果のみ再適用)
  reapply-items-on-join: true
```

変更したら `/hannyou knights reload` で反映できます。

## データの保存先

```
plugins/HANNYOU-Plugin/
├── config.yml            # 設定
├── roles.db              # 役職データ (SQLite)
├── exports/              # エクスポートしたファイル／インポートするファイル
└── logs/
    └── audit-YYYY-MM-DD.log   # 監査ログ
```

### KnightsEditor からの移行

データベースの形式が違うため、`knights_editor.db` はそのまま使えません。

1. KnightsEditor 側で `/knights export all` を実行します
2. 出力された `roles_all_*.yml` を `plugins/HANNYOU-Plugin/exports/` に置きます
3. `/hannyou knights import <ファイル名>` で読み込みます

## ビルド方法

```bash
./gradlew build
```

`build/libs/` に jar が出力されます。

テスト用のサーバーを起動して動作を確かめるには、次のコマンドを使います。初回は Minecraft の EULA に同意する必要があります（`run/eula.txt`）。

```bash
./gradlew runServer
```
