# HANNYOU-Plugin

Paper サーバー向けのプラグインです。現在は、プレイヤーに「役職」を付与して装備・インベントリ・永続ポーション効果を配る **Knights Editor** 機能を搭載しています。

Knights Editor は KnightsEditor を移植し、GUI の見た目はそのままに内部を作り直したものです。

---

## 特徴

- **GUI で役職を作成・編集** — 装備5箇所、インベントリ27枠、ホットバー9枠、ポーション効果32種（レベル I〜III）
- **手持ちから取り込み** — 今の自分の装備とインベントリを、そのまま役職の中身にできる
- **試着** — 役職を自分に一時的に適用して確認し、終わったら持ち物と効果を元に戻せる
- **コマンドでプレイヤーに付与** — `@a` などのセレクターで一括付与
- **永続効果** — 時間無制限で付与し、牛乳や不死のトーテムでは消えない。役職を保存すると保持者の効果もすぐ更新される
- **監査ログ** — 役職の操作をサーバーのログと OP のチャットに記録
- **軽量** — 役職データの保存は別スレッドで行い、サーバーの TPS を下げない

## 動作環境

| 項目 | バージョン |
|---|---|
| サーバー | Paper 26.1.2 |
| Java | 25 |

## 導入方法

1. [Releases](https://github.com/ukagaka-irono/HANNYOU-Plugin/releases) から `HANNYOU-Plugin-<version>-all.jar` をダウンロードします（自分で[ビルド](#ビルド方法)した場合は `build/libs/` にあります）
2. jar をサーバーの `plugins/` フォルダに置きます
3. サーバーを起動します

## 使い方

`/hannyou knights list` で役職一覧を、`/hannyou knights editor` で新しい役職のエディタを開けます。既存の役職を編集するときは `/hannyou knights editor <role id>` を使います。

### 役職エディタ

3ページ構成です。下段の左右の矢印でページを切り替えます。

| ページ | 内容 |
|---|---|
| 1. 装備・設定 | 左側で頭・胴・脚・足・オフハンドにアイテムを置く。右側で role id・アイコン（アイテムを置く）・表示名を設定する |
| 2. インベントリ | 上3段がインベントリ、4段目がホットバー |
| 3. 効果 | ポーションをクリックするたびに「なし → I → II → III → なし」と切り替わる |

表示名には `&c` のようなカラーコードが使えます。

下段のボタン:

| スロット | ボタン |
|---|---|
| 47 | 手持ちから取り込み |
| 49 | 閉じる（保存しない） |
| 50 | 保存 |
| 51 | 試着する |

- 編集は作業用のコピーに対して行い、「保存」を押したときだけ反映されます。
- 新しく作るときは、保存する前に1ページ目で role id（半角英数字とアンダースコア）を入力してください。自動では割り振られません。

### 役職一覧

| 操作 | 内容 |
|---|---|
| 左クリック | 編集 |
| 右クリック | コピー（コピー先の role id を入力） |
| Shift + 左クリック | 試着 |
| コンパス | ID・表示名で検索（右クリックで検索を解除） |
| 兵士の作成（下段の剣） | 新しい役職を作るエディタを開く |

### 試着

役職を自分に一時的に適用して、見た目や効果を確認できます。役職一覧の Shift + 左クリック、エディタの「試着する」、`/hannyou knights list <role id>` の【試着】から使えます。

- 試着前の持ち物と効果はプレイヤーデータに退避されます。役職のタグは付きません。
- チャットの **【試着を終了】** を押すと元に戻ります。エディタや役職一覧から試着した場合は、その画面に戻ります。
- ログアウト、死亡後のリスポーン、プラグインの停止でも自動で元に戻ります。サーバーが落ちた場合は、次の参加時に戻ります。【試着を終了】が押せなくなったとき（チャットが流れた、12時間以上たった）は、ログアウトして入り直してください。
- 試着中に死んでも、アイテムと経験値は落ちません。

> [!WARNING]
> 試着中にアイテムを捨てたりチェストに入れたりすると、そのアイテムは手元に残ったまま試着前の持ち物も戻るため、アイテムが増えます。試着は信頼できる管理者だけが使う前提です。

### 役職を付与したとき

- プレイヤーには role id のスコアボードタグが付き、装備・インベントリ・効果が配られます。**インベントリは役職の中身に置き換わります。**
- 別の役職に変えると、前の役職の効果は外れます。
- 参加時には役職の中身を配り直します（`reapply-items-on-join` で変更できます）。
- 役職を削除すると、オンラインの保持者からタグと効果が外れます（アイテムはそのまま）。オフラインの保持者は、次の参加時に外れます。
- role id を変更したときも、オフラインの保持者は次の参加時に新しい role id に付け替わります。削除した役職と同じ role id で別の役職を作り直しても、昔の保持者に新しい役職が付くことはありません。

### スペクモード

`/hannyou spec [対象]` で、観戦や進行役に向いた特別なクリエイティブモードにします。`/hannyou unspec [対象]` で解除すると、元のゲームモードに戻ります。対象を省略すると自分自身が対象になります。

- **見えない** — 体・装備・手に持った物・名前が、ほかのプレイヤーから見えなくなります（管理者も含む）。スペク中の人同士は半透明で見えます。タブリストには表示されたままです。
- **ぶつからない** — プレイヤーや Mob を押したり押されたりせず、矢などの飛び道具もすり抜けます。感圧板・トリップワイヤー・スカルクセンサーも反応しません。
- **操作できない** — ブロックの破壊・設置・右クリック、アイテムを捨てる・拾う・使う、攻撃、エンティティの操作、乗り物に乗ることができません。ダメージも受けません。
- クリエイティブなので飛行はできますが、クリエイティブインベントリからアイテムを取り出したり、持ち物を並べ替えたりはできません（中クリックでのアイテム入手も不可）。
- 解除するとスペク開始時の持ち物に戻ります。スペク中に役職を付与された場合は、付与された持ち物に戻ります。
- スペク中に死んでも、持ち物は落ちません。
- スペク中は試着できません。
- スペク中はゲームモードを変更できません。状態はログアウトや再起動をまたいで続きます。

> [!NOTE]
> 見えなくするために、スペク中の人は `hannyou_spec` というチームに入ります。元々チームに入っていた場合は、解除時にそのチームへ戻ります。

## コマンド

役職のコマンドは `/hannyou knights`、それ以外は `/hannyou` の下にあります。`/hannyou` や `/hannyou knights` だけを打つとヘルプが表示されます。ヘルプやボタンの多くはチャット上でクリックできます。

**役職（`/hannyou knights`）**

| コマンド | 説明 |
|---|---|
| `/hannyou knights list` | 役職一覧の GUI を開く（コンソールではチャットに一覧を出す） |
| `/hannyou knights list <role id>` | その役職の中身と【編集】【試着】【削除】ボタンをチャットに出す |
| `/hannyou knights editor [role id]` | 役職を新規作成するエディタを開く。role id を指定すると、その役職を編集する |
| `/hannyou knights give <対象> <role id>` | 役職を付与する |
| `/hannyou knights remove <role id>` | 削除の確認画面を開き、「削除する」か「やめる」を選ぶ |

**そのほか**

| コマンド | 説明 |
|---|---|
| `/hannyou spec [対象]` | [スペクモード](#スペクモード)にする（省略時は自分） |
| `/hannyou unspec [対象]` | スペクモードを解除する（省略時は自分） |
| `/hannyou reload` | `config.yml` を読み直す |

`<対象>` にはプレイヤー名のほか、`@a` `@s` `@p` `@r` などのセレクターが使えます。

```
/hannyou knights give @a warrior     # 全員に付与
/hannyou knights give Steve knight   # 特定のプレイヤーに付与
```

## 権限

すべてのコマンドと GUI は **OP だけ**が使えます（コンソールからも実行できます）。OP でないプレイヤーには、コマンド自体が表示されません。GUI を開いている途中で OP を外された場合も、それ以上は操作できません。

## 設定（config.yml）

```yaml
# 役職の作成・編集・削除などをサーバーのログと OP のチャットに記録する
log-role-changes: true

settings:
  # 登録できる役職の最大数 (-1 = 無制限)
  max-roles: -1
  # 参加時に役職の装備・インベントリを再配布する (false の場合はポーション効果のみ再適用)
  reapply-items-on-join: true
```

変更したら `/hannyou reload` で反映できます。

## データの保存先

```
plugins/HANNYOU-Plugin/
├── config.yml            # 設定
└── knights-role.yml      # 役職データ
```

`knights-role.yml` は役職を作成・編集・削除するたびに自動で書き出されます。

> [!NOTE]
> 手で編集するときは、サーバーを止めてから編集してください。動いている間に編集すると、次の保存で上書きされます。各役職の `uid` はプレイヤー側の記録と照らし合わせる識別番号なので、変更しないでください。読み込めない状態になっていた場合は `knights-role.yml.broken-<日時>` に退避し、役職なしで起動します。

## ビルド方法

```bash
./gradlew build
```

`build/libs/` に jar が出力されます。

テスト用のサーバーを起動して動作を確かめるには、次のコマンドを使います。初回は Minecraft の EULA に同意する必要があります（`run/eula.txt`）。

```bash
./gradlew runServer
```
